## Command Descriptions

### pwd

Display the current working directory.

### ls

List files and directories.

### cd

Change directory.

### cd ..

Move one directory back.

### cd ~

Return to the home directory.

### mkdir

Create a new directory.

### touch

Create an empty file.

### cat

Display file contents.
