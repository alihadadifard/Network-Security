# Lab 004

## Title

Basic Device Security

## Objective

Learn how to access Cisco devices using CLI and apply basic security configurations.

## Tools Used

* Cisco Packet Tracer

## Devices Used

* Router
* Switch

## Tasks Completed

* Entered CLI
* Accessed Privileged EXEC Mode
* Entered Configuration Mode
* Configured device hostname
* Configured console password
* Configured enable password
* Enabled password encryption
* Saved configuration

## Concepts Learned

* CLI Navigation
* Device Configuration
* Basic Device Security

## Result

Successfully configured basic security settings on Cisco devices.
