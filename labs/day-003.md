## Title

OSI Model

## Objective

Understand how devices communicate using layered network models and observe packet movement in Packet Tracer.

## Tools Used

* Cisco Packet Tracer

## Devices Used

* PC
* Switch
* Router
* Server

## Tasks Completed

* Opened the Packet Tracer lab
* Explored device communication
* Observed packet movement
* Examined communication between network layers
* Saved the Packet Tracer project

## Concepts Learned

* OSI Model
* Layered Communication
* Encapsulation
* Decapsulation
* Protocol Data Unit (PDU)
* Device Communication

## Lessons Learned

* Data moves through multiple network layers.
* Each layer has a specific responsibility.
* Encapsulation adds information to data.
* Decapsulation removes information at the destination.
* Layered models simplify network communication.
