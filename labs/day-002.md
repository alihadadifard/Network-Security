# Lab 002

## Title

Connecting Devices

## Objective

Learn how to connect network devices using the correct cable types in Packet Tracer.

## Tools Used

* Cisco Packet Tracer

## Devices Used

* PC
* Switch
* Router

## Cable Types Used

* Straight-Through Cable
* Crossover Cable
* Fiber-Optic Cable

## Tasks Completed

* Added devices to the workspace
* Connected devices using appropriate cables
* Connected a PC to a Switch
* Connected a Switch to a Router
* Explored different cable types
* Saved the Packet Tracer lab

## Lessons Learned

* Different devices require different cable types.
* Network connectivity begins at the physical layer.
* Packet Tracer can simulate real network environments.

Successfully completed the Connecting Devices lab and learned how to connect network devices using the correct cable types.
