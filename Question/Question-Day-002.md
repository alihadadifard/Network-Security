# Question Day 002

## 1. What is a Network Interface?

Answer:
A Network Interface is a connection point on a device that allows it to communicate with other devices on a network.


## 2. What is an Ethernet Interface?

Answer:
An Ethernet Interface is a network interface used for Ethernet communication.


## 3. What is an RJ45 Connector?

Answer:
RJ45 is a standard connector used for Ethernet cables.


## 4. What is Ethernet?

Answer:
Ethernet is a set of standards used for wired local area networks (LANs).


## 5. What is a Straight-Through Cable?

Answer:
A Straight-Through cable is commonly used to connect different types of devices, such as a PC to a switch.


## 6. What is a Crossover Cable?

Answer:
A Crossover cable is commonly used to connect similar devices, such as a switch to another switch.


## 7. What is a Fiber-Optic Cable?

Answer:
A Fiber-Optic cable transmits data using light instead of electrical signals.


## 8. What is Single-Mode Fiber?

Answer:
Single-Mode Fiber uses a small core and supports longer transmission distances.


## 9. What is Multi-Mode Fiber?

Answer:
Multi-Mode Fiber uses a larger core and is designed for shorter distances.


## 10. Which fiber type supports longer distances?

Answer:
Single-Mode Fiber supports longer distances than Multi-Mode Fiber.


## 11. Which cable is commonly used between a PC and a Switch?

Answer:
A Straight-Through cable.


## 12. Which cable is commonly used between two Switches?

Answer:
A Crossover cable.
