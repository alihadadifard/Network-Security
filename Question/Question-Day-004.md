# Question Day 004

## 1. What is CLI?

Answer:
CLI stands for Command Line Interface and allows users to configure devices using commands.

---

## 2. What is User EXEC Mode?

Answer:
User EXEC Mode provides limited monitoring access.

---

## 3. What is Privileged EXEC Mode?

Answer:
Privileged EXEC Mode provides administrative access to device commands.

---

## 4. What command enters Privileged EXEC Mode?

Answer:
enable

---

## 5. What command enters Global Configuration Mode?

Answer:
configure terminal

---

## 6. What command changes the device name?

Answer:
hostname

---

## 7. Why should passwords be configured?

Answer:
To protect administrative access to the device.

---

## 8. What does password encryption do?

Answer:
It stores passwords in encrypted form instead of plain text.
