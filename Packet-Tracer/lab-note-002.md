# Lab 002

## Title

Connecting Devices

## Objective

Learn how to connect network devices using the correct cable types in Packet Tracer.

## Devices Used

* PC
* Switch
* Router

## Cable Types Used

* Straight-Through Cable
* Crossover Cable
* Fiber-Optic Cable

## Tasks Completed

* Connected a PC to a Switch
* Connected a Switch to a Router
* Connected network devices using appropriate cables
* Verified physical connectivity

## Lessons Learned

* Different devices require different cable types.
* Physical connectivity is the foundation of networking.
* Packet Tracer helps visualize network connections.
