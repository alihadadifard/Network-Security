# Lab 001

## Title

Packet Tracer Introduction

## Objective

Learn the Packet Tracer interface and become familiar with the basic workspace and networking devices.

## Tools Used

- Cisco Packet Tracer

## Devices Explored

- PC
- Laptop
- Server
- Switch
- Router

## Tasks Completed

- Opened Packet Tracer
- Explored the Packet Tracer workspace
- Examined device categories
- Added devices to the topology
- Connected devices using Packet Tracer
- Observed interfaces and connections
- Saved the Packet Tracer project

## Concepts Learned

- Network Topology
- Nodes
- Network Devices
- Interfaces
- Connections
- Simulation Environment

## Lessons Learned

- Packet Tracer is a network simulation tool.
- Network devices can be placed in a virtual environment.
- Devices can be connected without physical hardware.
- Packet Tracer will be used throughout the CCNA journey.

## Result

Successfully completed the first Packet Tracer lab and became familiar with the Packet Tracer environment and basic network device placement.
