#  Packet Tracer Introduction

## What is Packet Tracer?

Packet Tracer is a network simulation software developed by Cisco.
It allows users to build, configure, and test network topologies without physical hardware.

## Why is Packet Tracer Important?

* Helps learn networking concepts.
* Allows network design and testing.
* Provides a safe environment for experiments.
* Widely used for CCNA studies.

## Features

* Create network topologies
* Add routers, switches, PCs, and servers
* Configure network devices
* Simulate packet flow
* Practice troubleshooting

## New Terms

### Topology

A network layout showing how devices are connected.

### Node

Any device connected to a network.

### Link

A connection between two network devices.

### Packet

A unit of data transmitted across a network.

### Simulation

A virtual representation of a real network environment.
